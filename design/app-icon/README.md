The generated source is `kidfocus-icon-source.png`. It is used to derive:

- `app/src/main/res/drawable-nodpi/kidfocus_launcher_foreground.png` for the Android adaptive icon.

## Design direction

The owl and open book make learning the primary message. The small clock preserves the focus-timer
heritage without positioning the whole app as only a timer. The blue, turquoise, white, and yellow
palette matches the existing KidFocus interface and remains readable under common launcher masks.

## Final image-generation prompt

Use case: logo-brand. Create a production-ready square mobile app icon for KidFocus. Center one
friendly, clever owl mascot holding an open book. Integrate one small, clean clock motif into the
book as a secondary detail. Use a strong compact silhouette, polished vector-style illustration,
crisp edges, generous safe padding, KidFocus blue `#1565C0`, bright turquoise, warm golden yellow,
and white pages. Use a simple full-bleed blue-to-turquoise background. No text, letters, numbers,
watermarks, graduation cap, alarm-clock bells, thin lines, clutter, or separate floating objects.
Keep essential artwork within the adaptive-icon safe zone.
